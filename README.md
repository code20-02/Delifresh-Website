## 🥗 Delifresh Website

A static website for **DeliFresh**, showcasing products, services, case studies, and online ordering pages.  
The project is built using **HTML, CSS, and JavaScript**, along with supporting assets, to deliver a complete multi-page web experience.

This website represents the **front-end implementation for a food supply and deli ingredients business**, inspired by the official Delifresh brand structure. It includes essential business pages such as **About**, **Products**, **Services**, **Contact**, **Online Ordering**, and related informational sections.
